SlideSmith Windows Bundle
=========================

This bundle is intended for Mod Organizer 2 / Vortex managed installs.

Included:
- desktop/SlideSmith.exe
- cli/SlideSmith-CLI.exe
- fomod/ metadata
- meta.ini
- meta/slidesmith-bundle.json

Quick start:
1) Install this bundle as a mod/tool package in your mod manager.
2) Point your executable entry to desktop/SlideSmith.exe (GUI) or cli/SlideSmith-CLI.exe (CLI).
3) Keep this package enabled as a separate managed entry.
